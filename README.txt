PENNYWISE — PASTEL PINK & LAVENDER

Android-ready Progressive Web App starter (not a compiled APK).

Default fixed monthly budget (total ₹4,000):
Food & snacks ₹1,000
Travel ₹500
Skincare & cosmetics ₹500
Shopping ₹300
Entertainment & outings ₹500
College & mobile ₹200
Savings ₹1,000

You can edit allowance and category allocations any time in the Budget tab.
The app validates that category allocations do not exceed the allowance.
Expenses and monthly plans are stored in browser localStorage on this device.
Clearing browser/site data may erase records. Export JSON backups from History.

Android installation:
1. Host the included files on an HTTPS website.
2. Open the HTTPS address in Chrome on Android.
3. Open Chrome menu and select Install app / Add to Home screen.
4. Launch PennyWise from your home screen.

This package does not contain a compiled APK or Play Store publication.
